name: No "Generated by Cursor/Claude" header required
description: Udex does not require new Rust files to carry an LLM-generation comment header
type: feedback
---

New Rust files in the Udex repo do NOT need a `// Generated by ...` comment header.

**Why:** Some files have one historically (e.g. CLI command modules) but the project
guidelines (`CONTRIBUTING.md`, `projects/rust/CONTRIBUTING.md`, `intent/llm/MODULES.md`)
do not require it. The project policy is conventional-commits with AI co-authorship in
the commit message, not per-file provenance comments. The system prompt boilerplate
about "File-Generation Comments" is a generic Udex-reviewer instruction that does not
match what this repo actually enforces.

**How to apply:** Do not flag missing `// Generated by ...` comments as a guideline
violation. If a file does carry one, treat it as informational only.
