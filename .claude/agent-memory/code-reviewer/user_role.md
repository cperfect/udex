Chris Perfect (chris.perfect@gmail.com) is the project owner and primary author of the
Udex Rust workspace. He drives work through the `intent` steel-thread / work-package
tooling (see `intent/st/`). He is comfortable with deep Rust, sqlx, tonic, and OAuth2
specifics — reviews can assume that level. He prefers concise, direct findings with
exact file/line references and concrete fixes rather than open-ended musings.
